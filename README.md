# OpenBench

Benchmarks for AmigaOS 3.2: small, repeatable programs that time what Amiga software really does (loops, copies, sorts, strings, maths, graphics calls), so the same program can be run on a real 68k, on AmigaChrome's AC090 and on any other Amiga, and the results compared.

Part of the Open family. MIT licensed and free.

## Status

New. The first benchmarks come from the Team's compiler work (GCC 16.2 for AmigaOS: shift loops, sorted insert, CRC-32, sieve, quicksort, matrix and string tests).
